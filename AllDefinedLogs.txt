HW#3 AllDefinedLogs.txt — 프로그램에서 남기는 모든 로그 메시지
====================================================================

공통 형식
  [HH:MM:SS.mmm] NODE | EVENT | STATUS | message
  - 시각: 실제 시각, KST(Asia/Seoul)
  - NODE: COORD, WORKERi (i = 1~10), LAUNCHER
  - STATUS: SUCCESS, FAIL, INFO, WARN
  - 로그 파일: Coordinator.txt, Worker1.txt ~ Worker10.txt, Launcher.txt
  - 아래 표기: {i} Worker 번호, {k} Task 번호, {e} epoch, {s} step, {v} 결과값, {p} partial
  - 시각 t= 값은 START(Launcher는 t0) 기준 초, lastHB= 도 START 기준 초

crash 한 주기 추적 방법
  Launcher.txt  CRASH  #n victim=W{d}
  Coordinator   SUSPECT W{d} → DEAD W{d} (owned, next_alive, dead_now) → TAKEOVER task={k} ... owner W{d}->W{b}
  Worker{b}     TAKEOVER task={k} e{e} from W{d} ... resume step / start step 1 → RESULT → COMMIT(ACK)
  Launcher.txt  RESTART W{d} → Worker{d} RESTART, REJOIN
  Coordinator   REJOIN W{d} DEAD->ALIVE → ASSIGN task={k} e1 -> W{d} (first task after rejoin)
